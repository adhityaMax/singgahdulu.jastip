# singgahdulu.jastip

Aplikasi operasional jastip dengan React, Vite, dan Supabase.

```sh
npm install
npm run dev
```

Jalankan [schema SQL](supabase_schema.sql) di Supabase SQL Editor, lalu ikuti [panduan database dan akun pengguna](TUTORIAL_DATABASE_SUPABASE.md).

Validasi: `npm run build`, `npm run lint`, dan `node --test tests/persistence.test.mjs`.
